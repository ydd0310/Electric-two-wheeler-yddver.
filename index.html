如何获取 Personal Access Token？
1. 打开 github.com/settings/tokens
2. 点击 Generate new token (classic)
3. 勾选 repo 权限 → 生成并复制 token
4. 粘贴到下方输入框（token 仅保存在你本地浏览器中）
